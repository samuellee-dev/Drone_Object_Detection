# ─── 온디바이스(NVIDIA Jetson) 환경 안내 ───
#
# Jetson은 ARM64(aarch64) + 구형 CUDA(10.2) 환경으로,
# 위 목록의 onnxruntime-gpu / torch를 그대로 설치하면 GPU 가속이 동작하지 않는다.
# PyPI 배포본은 x86_64 + 최신 CUDA 기준으로 빌드되어 있어,
# 설치가 되더라도 CPU로 fallback되며 에러 없이 FPS만 크게 저하된다.
#
# Jetson에서는 JetPack 버전에 맞는 NVIDIA 제공 wheel을 별도 설치할 것.
#   - onnxruntime-gpu     : NVIDIA Jetson Zoo 배포 wheel
#   - torch / torchvision : NVIDIA 제공 Jetson 전용 빌드
#   - opencv-python       : pip 설치 금지. 시스템 OpenCV 사용 권장
#                           (pip으로 덮어쓰면 CUDA 지원이 빠진 빌드로 교체됨)
#                           확인: python3 -c "import cv2; print(cv2.__version__)"
#   - ultralytics, onnx   : pip 설치 가능
#
# 설치 후 GPU 가속 동작 확인:
#   python3 -c "import onnxruntime as ort; print(ort.get_available_providers())"
#   -> CUDAExecutionProvider가 목록에 있어야 정상
#   -> CPUExecutionProvider만 나오면 wheel이 잘못 설치된 것
